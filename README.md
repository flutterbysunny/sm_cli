# 🚀 SM CLI (Flutter Clean Architecture Generator)

A powerful CLI tool to generate production-ready Flutter architecture with Riverpod, GoRouter, Dio, and feature-based structure.

---

## ✨ Features

- Flutter project initializer
- Feature-based architecture generator
- Riverpod state management setup
- API layer (Dio-based)
- Auto routing system
- Theme setup
- Clean folder structure

---

## 📦 Installation

```bash
dart pub global activate sm_cli
